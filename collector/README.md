# Google 스프레드시트 응답 수집

이 저장소의 `Code.gs`와 `appsscript.json`은 연구자 소유의 Google Apps Script 프로젝트에 설치합니다. 스프레드시트 자체의 공유 범위는 비공개로 유지합니다.

응답 시트: https://docs.google.com/spreadsheets/d/1htVh5n2nwifx3gYlVof1b3CIIcgk1kmzLKLduFN3znY/edit

1. 위 스프레드시트에서 확장 프로그램 → Apps Script를 엽니다.
2. `Code.gs`를 이 폴더의 내용으로 교체하고 저장합니다.
3. `setup`을 실행해 탭과 열을 확인하고 한국 시간대를 적용합니다. 최초 실행은 소유자의 Google 권한 승인이 필요합니다.
4. 배포 → 새 배포 → 웹 앱을 선택합니다. 실행 사용자: 본인, 액세스 사용자: 모든 사용자(로그인 없이 참여 가능).
5. 배포된 `/exec` URL을 프런트엔드의 `SETTINGS.responseEndpoint`에 넣고, `allowedCollectorOrigins`에 `https://script.google.com`을 넣습니다.
6. 별도의 시험 응답을 제출하고, 실제 시트에 모든 탭의 행이 생겼는지와 재시도 시 중복이 생기지 않는지 확인합니다. 시험 응답임을 분석에서 구분하고 실제 참여 결과에 섞지 않습니다.
7. 저장 검증 후 `previewMode: false`로 전환합니다. 연결이 비어 있는 상태에서 배포 완료로 안내하지 않습니다.

Apps Script 요청은 JSON 내용을 `text/plain`으로 전송하고 리디렉션을 따라갑니다. 서버가 실제 저장 후 같은 `submissionId`를 반환해야 제출 완료로 표시합니다. `no-cors` 방식으로 성공 여부를 추정하지 않습니다.

‘참여자’는 마지막에 쓰는 제출 확인 기록입니다. 중간 쓰기 실패 후 재시도하면 해당 제출 ID의 미완성 하위 행만 정리하고 다시 저장합니다. 이미 완료된 같은 ID는 새 행을 만들지 않습니다.

공개 웹 앱은 응답을 쓰는 기능과 내용 없는 상태 확인만 제공합니다. 응답을 읽는 API는 제공하지 않습니다. 결과는 소유자의 비공개 스프레드시트에서 확인합니다.

현재 수집 시점은 마지막 ‘응답 제출하기’입니다. 진행 중 답변은 기기에 임시 저장되어 새로고침 후 이어서 작성할 수 있습니다.
